# 🚀 Quick Start - New Features

## What's New in Your Enhanced Wkly

I've added powerful features to make your weekly planning faster and more enjoyable!

## ⚡ 3 Things to Try Right Now

### 1. Keyboard Shortcuts (Press `?`)
- `Ctrl+N` - Create new task instantly
- `/` - Quick search
- `Ctrl+F` - Focus mode with Pomodoro
- `Esc` - Close anything

### 2. Task Templates (Click ✨)
When creating a new task:
1. Click the sparkle icon ✨ in the modal
2. Choose from 8 templates
3. Pre-filled checklist ready to go!

Templates include:
- Meeting workflow
- Code review checklist  
- Workout routine
- Content creation
- Shopping list
- Project setup
- Study session
- Blog post workflow

### 3. Subtasks with Progress
- Add checklist items to any task
- Press Enter to quickly add items
- Watch progress bar fill up
- Get visual feedback as you complete

## 🎯 Speed Tips

**Fastest task creation ever:**
1. Press `Ctrl+N`
2. Click a template
3. Press Enter on each subtask
4. Done in 10 seconds!

**Navigate like a pro:**
- `Ctrl+←/→` - Switch weeks
- `Ctrl+T` - Jump to today
- `/` - Search everything

## 📊 Before/After

**Before**: Click "Add task" → Type everything → Click save → Repeat  
**After**: `Ctrl+N` → Pick template → Press Enter 3 times → Done!

**Time saved per task**: ~30 seconds  
**Time saved per week**: ~15 minutes  
**Feels**: Much more professional ✨

## 🗄️ One-Time Setup

Run this migration in Supabase SQL Editor:
```
supabase-migration-subtasks.sql
```

This enables the subtasks/checklists feature.
