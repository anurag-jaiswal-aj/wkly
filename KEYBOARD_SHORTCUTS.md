# Wkly Keyboard Shortcuts

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `Tab` | Navigate between interactive elements |
| `Shift + Tab` | Navigate backwards |
| `Enter` | Activate focused element |
| `Escape` | Close modal or cancel action |

## Navigation

| Shortcut | Action |
|----------|--------|
| `←` | Previous week |
| `→` | Next week |
| `T` | Jump to today *(coming soon)* |

## Drag & Drop

| Action | Method |
|--------|--------|
| Drag task | Click and hold, then drag |
| Cancel drag | Press `Escape` while dragging |

## Tips

1. **Efficient Task Creation**
   - Use the "+ Add task" button in the desired day
   - Title is focused automatically
   - Press Tab to navigate fields
   - Press Enter to create

2. **Quick Editing**
   - Click any task to edit
   - Modal opens with focus on title
   - Make changes and press Enter

3. **Drag Performance**
   - Click and hold for a moment before dragging
   - Smooth dragging with visual feedback
   - Drop on any day column

4. **Theme Switching**
   - Click sun/moon icon in header
   - Preference saved automatically
   - Syncs with system preference
